# Simple Kitchen

Week 4 Day 3 lab: the Simple Kitchen page and Form Demo combined with Express, Pug, Sass, and MongoDB.

1. Run `npm install` and start a local MongoDB server.
2. Copy `.env.example` to `.env`.
3. Run `npm run watch` for the app. Run `npx sass --watch public/scss:public/css` to edit styles.
4. Visit `http://localhost:3000/` and use Register to save a record.

Set `ADMIN_USER` and `ADMIN_PASSWORD` in `.env` to enable the protected registrations list. Do not commit `.env`.
